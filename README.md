# Gödel Trader

A recursively self-improving agent for trading-strategy research.
Stanford CS 329Z (Engineering AI Agents), Fall 2026 course project.

This repository is being set up for the midpoint milestone. Instructions for
installing dependencies, configuring API keys, running the agent, and
reproducing the reported results will be added here.

## Layout

- `notes/` : project proposal, course project description, and the two papers
  this work builds on (Gödel Agent and R&D-Agent(Q)).
